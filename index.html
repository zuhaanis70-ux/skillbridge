Responsible Use

SkillBridge supports decisions — it does not replace human judgment.

Human review

Recommendations are suggestions only. Managers make the final staffing decision.

Explainability

The system shows the skills and evidence contributing to each recommendation.

Data minimisation

The prototype uses only information relevant to expertise, experience and project staffing.

Profile correction

Employees should be able to review and correct their expertise information.

Fairness and bias monitoring

Availability and other workforce attributes should not be used as hidden proxies for unrelated personal characteristics.

Responsible AI use

Human oversight, transparency, data minimisation and regular review are essential before deploying the system in a real organisation.
